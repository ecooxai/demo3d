# Tiamat

A real-time 3D comet over a night rooftop skyline.

- [Open the interactive viewer](https://ecooxai.github.io/demo3d/comentnight-astra6.2/)
- [Watch the one-minute film and view four stills](https://ecooxai.github.io/demo3d/comentnight-astra6.2/showcase.html)

The viewer tries WebGPU first. If WebGPU is unavailable or does not meet the on-device frame-rate gate, use the explicit WebGL2 option.

Created with GPT-6.2-Astra, OpenAI Dot, and Wtruby.
